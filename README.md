# 💳 Digital Bank Landing Page

A modern and responsive banking landing page built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

🔗 https://rezafrontenddeveloper.github.io/Digital-Bank-Landing-Page/

---

## 📖 About The Project

Digital Bank Landing Page is a responsive front-end project inspired by modern digital banking websites. The goal of this project was to practice building clean and responsive user interfaces using only HTML, CSS, and Vanilla JavaScript.

The website includes a hero section, banking features, latest articles, a responsive navigation menu, and a modern footer. Special attention was given to responsive design to ensure a smooth user experience across different screen sizes.

---

## ✨ Features

- Fully Responsive Design
- Fixed Navigation Header
- Mobile Hamburger Menu
- Hero Section with Call-to-Action
- Banking Features Section
- Latest Articles Section
- Modern Footer Layout
- CSS Variables for Easy Customization
- Clean and Organized Code Structure
- Vanilla JavaScript Navigation Toggle

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
